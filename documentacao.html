documentação técnica cproeis automação

guia completo da arquitetura híbrida: aplicativo desktop electron conectado a api central na nuvem.

1. arquitetura híbrida

o sistema opera no modelo híbrido de alta eficiência, dividindo responsabilidades entre nuvem e máquina local para garantir 100% de taxa de sucesso e evitar bloqueios por ip:

servidor na nuvem (easypanel)

central de banco de dados e api

hospeda a api fastapi, autenticação jwt e o banco de dados de clientes, usuários e histórico. responde em json na raiz e opera com consumo mínimo (menos de 60mb de ram).

aplicativo desktop (electron local)

interface nativa e motor de automação

executa localmente na sua máquina com ip residencial brasileiro. consome os clientes da api na nuvem e roda o playwright em segundo plano sem risco de timeout ou bloqueio de firewall.

2. aplicativo desktop electron (.exe)

o aplicativo desktop reúne toda a interface react moderna dentro de um executável nativo do windows.

módulos inclusos no aplicativo desktop:

  • painel de controle: seleção de cliente ativo, modo (homologação ou produção), acionamento de automação e consulta de vagas com terminal de logs em tempo real.
  • gestão de clientes: cadastro completo de clientes (cpf, senha, convênio, eventos preferidos, datas e metas de vagas).
  • comprovantes: visualização e download dos comprovantes de agendamento gerados em pdf.
  • configurações do sistema: ajuste de parâmetros padrão e chaves api.
  • gestão de usuários: gerenciamento de operadores e administradores master.

3. gerar instalador nsis (.exe)

o projeto possui um script automatizado para gerar o instalador do windows no padrão clássico nsis (avançar > escolher pasta > instalar > criar atalho > concluir).

passo a passo para gerar o instalador:

  1. dê dois cliques no arquivo gerar_instalador_desktop.bat na raiz do projeto.
  2. o script compilará a interface react com o vite e construirá o instalador pelo electron-builder.
  3. ao concluir, a pasta dist_instalador será aberta automaticamente com o arquivo do instalador executável.
call gerar_instalador_desktop.bat

4. servidor api na nuvem (easypanel)

o servidor online funciona estritamente como backend de dados e api rest.

resposta da rota raiz:

ao acessar https://cprsautomacao.devsouza.online/ no navegador, o servidor retorna o status em formato json:

{ "status": "online", "service": "CPROEIS API Server", "version": "1.0.0" }

variáveis de ambiente no easypanel:

chave exemplo de valor descrição
PORT 3000 porta interna do container
ADMIN_EMAIL luansouza.tl29@gmail.com email master de acesso e sincronização
ADMIN_PASSWORD sua_senha_segura senha master de acesso
SECRET_KEY chave_jwt_secreta_longa chave para assinatura de tokens jwt
DATABASE_URL sqlite:////app/data/cproeis.db caminho do banco persistente no volume

5. agente local de terminal

além do aplicativo desktop em electron, você também conta com o agente rápido de terminal para execuções ágeis:

como utilizar o agente:

  1. dê dois cliques no arquivo iniciar_agente_nuvem.bat.
  2. o agente autentica na api do servidor online e lista todos os clientes cadastrados.
  3. escolha a opção desejada no menu interativo (executar homologação, produção, consulta de vagas ou execução em lote).
  4. o robô roda 100% em segundo plano (headless) e exibe os logs no próprio terminal.

6. funcionamento do robô e regras de negócio

o motor de agendamento automatizado executa as seguintes etapas:

  1. autenticação: acessa a tela de login do portal cproeis, seleciona o tipo de documento, preenche as credenciais e decodifica o captcha automaticamente via ddddocr com pré-processamento opencv (com suporte a fallback gemini ai).
  2. módulo de escala: navega até a área de voluntários/escala e seleciona o convênio configurado para o cliente.
  3. varredura de datas: percorre as datas configuradas (modo intervalo fixo ou dias à frente, ex: +6 a +7 dias).
  4. filtro e pontuação de vagas: avalia as vagas disponíveis conforme as regras de eventos preferidos, prioridade de vagas titulares e meta configurada.
  5. confirmação e agendamento: inscreve o voluntário e finaliza o ciclo ao atingir a meta estipulada.

7. consulta de vagas e comprovantes em pdf

o módulo de consulta permite verificar em tempo real os eventos já confirmados no portal do proeis para o cliente:

  • acessa a tela de voluntários e ativa a exibição do mês corrente.
  • extrai o relatório de escalas confirmadas.
  • gera automaticamente um documento pdf formatado contendo cabeçalho institucional, nome do evento, convênio, data/hora, ponto de encontro e endereço.
  • salva o arquivo na pasta comprovantes/.
