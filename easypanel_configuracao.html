guia de configuração no easypanel

passo a passo para implantação do sistema cproeis automação a partir do repositório git

1. criação do serviço

tipo: app

no painel do seu projeto no easypanel, clique no botão para adicionar um novo serviço e selecione a opção app.

nome do serviço

cproeis-automacao

tipo de implantação

github / git repository

2. aba source (código fonte)

origem do código

configure a origem para buscar os arquivos diretamente do github:

campo valor a preencher descrição
repository https://github.com/souzahub/cproeisautomacao.git url do repositório git criado
branch main ramificação principal de produção
auto deploy habilitado atualiza a aplicação a cada novo commit

3. aba build (construção da imagem)

dockerfile

o projeto possui um dockerfile otimizado em múltiplos estágios (build do frontend em react e ambiente python com playwright/chromium):

campo valor a preencher
build type Dockerfile
dockerfile path Dockerfile (ou /Dockerfile)
build context . (ou /)

4. aba environment (variáveis de ambiente)

obrigatório

na aba environment do easypanel, adicione as seguintes variáveis de configuração:

chave (key) valor sugerido (value) descrição
PORT 3000 porta onde o servidor uvicorn escuta
SECRET_KEY cproeis_secret_key_producao_2026_segura chave secreta para geração dos tokens jwt
INITIAL_MASTER_EMAIL admin@cproeis.com email inicial do usuário administrador master
INITIAL_MASTER_PASSWORD admin123456 senha do usuário master inicial
PROEIS_URL https://www.proeis.rj.gov.br/ endereço do portal cproeis oficial
MODO_VISIVEL false execução do navegador em modo headless no servidor
MODO_HOMOLOGACAO true modo padrão ao inicializar (teste ou produção)
DATABASE_URL sqlite:////app/data/cproeis.db caminho do banco de dados sqlite persistente
GEMINI_API_KEY (opcional) chave api do google gemini caso deseje usar o modelo
GEMINI_MODEL gemini-3.7-flash versão do modelo gemini

bloco bruto para copiar e colar no easypanel:

PROEIS_URL=https://www.proeis.rj.gov.br/ PORT=3000 MODO_VISIVEL=false MODO_HOMOLOGACAO=true SECRET_KEY=BJXRSJcUJPfve5ZPoMa9tY61fY25MCK2g7Uopjr8ljhlAddawxFFIDIYZdVGuhlh INITIAL_MASTER_EMAIL=admin@cproeis.com INITIAL_MASTER_PASSWORD=admin123456 DATABASE_URL=sqlite:////app/data/cproeis.db GEMINI_API_KEY= GEMINI_MODEL=gemini-3.7-flash

5. aba mounts / volumes (persistência)

recomendado

para garantir que clientes cadastrados, usuários, históricos e comprovantes pdf não sejam apagados a cada reinicialização ou atualização do container, configure os volumes:

tipo caminho no container (mount path) finalidade
Volume / Persist /app/data guarda o arquivo de banco de dados cproeis.db
Volume / Persist /app/comprovantes guarda os comprovantes de agendamento em pdf gerados

6. aba domains / portas

acesso externo

ao adicionar ou atualizar o domínio no modal atualizar domínio do easypanel, preencha exatamente assim:

campo no modal valor a preencher explicação
HTTPS ativado gera certificado ssl gratuito automaticamente
Host * seu domínio ou subdomínio (ex: cprsautomacao.ycwhxf.easypanel.host) endereço web da sua aplicação
Caminho * / rota raiz
Protocolo * HTTP comunicação interna do proxy com o container
Porta * 3000 porta do backend uvicorn
Serviço Compose * app nome do serviço definido no docker-compose.yml

7. implantação e primeiro acesso

execução
  1. clique no botão deploy no canto superior do easypanel.
  2. acompanhe a construção na aba logs / deployments até exibir o status running.
  3. acesse o domínio configurado no navegador.
  4. faça login com o usuário master configurado em INITIAL_MASTER_EMAIL e INITIAL_MASTER_PASSWORD.
  5. cadastre os clientes na aba clientes e teste a automação e a consulta de vagas.
dica: no servidor linux é essencial manter MODO_VISIVEL=false para que o chromium execute sem necessidade de servidor gráfico x11.
